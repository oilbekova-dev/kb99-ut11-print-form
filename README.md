# Внешняя печатная форма «Акт списания товаров» для 1С:УТ 11.5

Внешняя печатная форма (ВПФ) для документа **«Списание недостач товаров»** (`Документ.СписаниеНедостачТоваров`).

## Состав репозитория
* `ПечатьСписанияУТ.epf` — готовый файл внешней обработки для подключения в режиме *1С:Предприятие* (*НСИ и администрирование ➡️ Дополнительные отчеты и обработки*).
* `ПечатьСписанияУТ.xml` и каталог `ПечатьСписанияУТ/` — выгруженные XML-исходники конфигурации, макета и серверного кода (`ObjectModule.bsl`).
